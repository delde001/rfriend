# Package index

- [`df_to_table()`](https://delde001.github.io/rfriend/reference/df_to_table.md)
  : Convert a data frame to a contingency table

  Perform multiple [`aov()`](https://rdrr.io/r/stats/aov.html) functions

  : Generate a Boxplot Report of a data.frame

  : Chi-squared Test with post hoc Analysis

- [`f_clear()`](https://delde001.github.io/rfriend/reference/f_clear.md)

  : Perform multiple Friedman rank sum tests with a user-friendly output
  file, do data inspection and pairwise Wilcoxon signed-rank tests as
  post hoc.

- [`f_glm()`](https://delde001.github.io/rfriend/reference/f_glm.md) :

  Perform multiple [`glm()`](https://rdrr.io/r/stats/glm.html) functions
  with diagnostics, assumption checking, and post hoc analysis

- [`f_hist()`](https://delde001.github.io/rfriend/reference/f_hist.md) :
  Plot a Histogram with an Overlaid Normal Curve

- [`f_kruskal_test()`](https://delde001.github.io/rfriend/reference/f_kruskal_test.md)
  : Perform multiple Kruskal-Wallis tests with a user-friendly output
  file, do data inspection and Dunn's test (of 'rstatix') as post hoc.

- [`f_lm()`](https://delde001.github.io/rfriend/reference/f_lm.md) :

  Perform multiple [`lm()`](https://rdrr.io/r/stats/lm.html) functions
  with optional data transformation, inspection, regression plots and
  post hoc test.

- [`f_lmer()`](https://delde001.github.io/rfriend/reference/f_lmer.md) :

  Fit a linear mixed model with
  [`lme4::lmer()`](https://rdrr.io/pkg/lme4/man/lmer.html) including
  assumption checks, diagnostics, R-squared and post hoc tests.
